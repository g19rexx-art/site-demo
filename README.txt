BWAiSE CLEAN & SAFE
Community Waste Management and Flood Reporting System

PROJECT DESCRIPTION
A front-end student project prototype for environmental awareness, waste collection information and reporting environmental concerns in Bwaise, Kawempe Division, Kampala, Uganda.

HOW TO RUN
Open the project folder in Visual Studio Code, open index.html and use Live Server.

PHOTOGRAPHS
The pages include illustrative photographs loaded from third-party publisher websites. An internet connection is required. They are not verified photographs of Bwaise. See images/IMAGE-SOURCES.txt for image source links and reuse notes.

PROTOTYPE LIMITATIONS
The current front end does not connect to a shared database or live authority. Report metadata is stored only in the browser where it is submitted. Uploaded photographs are validated but not uploaded. Waste collection requests and contact messages are not sent to external providers. The Admin Dashboard is illustrative and has no secure login.


LOCAL IMAGE UPDATE
The photographs now use Ugandan locations and community settings, including Buikwe, Kampala, Natete, Papoli and the Kalerwe-Bwaise road corridor. They are illustrative and should not be described as verified photographs of Bwaise unless the caption identifies the exact location.
